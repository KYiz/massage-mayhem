# 《疯狂按摩店》视觉概念与资源生产清单

版本：参考图定向 v1。以下 8 张用户参考图为风格依据，5 张新图为**概念图**。概念图是构图和材质方向，均为整张 PNG；不能直接当游戏中的可动角色、透明道具、热区或背景分层使用。最终可运行资源须按本清单重绘、拆层与导出。

## 1. 参考图提炼与优先级

| 参考 | 本次采用的设计信息 |
|---|---|
| 01、03 开背横／竖屏 | 中央大面积按摩操作区；顾客脸可见；左侧五状态条；右侧顾客档案；底部道具卡与操作提示。横竖屏是两套重排，不是简单裁切 |
| 05 压腿、08 足疗 | 三个场景共用同一 HUD 与文件卡框架；每关只替换操作部位、热区示意图、技师姿态和道具 |
| 04 角色阵容、07 技师选择 | 人物黑色粗外轮廓、暖肤色、黑／酒红制服、显著发型与体型差异；技师轮盘以大立绘居中、未解锁灰显 |
| 02 失败结算 | 屏幕左侧是事件插画，右侧纸质失误清单；红色投诉章、冷蓝警灯，风险原因逐项可读 |
| 06 稀有客 | 金色逆光剪影、强轮廓、问号与徽章；接受／拒绝为并列大按钮 |

**本轮锁定的风格**：偏厚描边的高完成度 2D 动漫卡通，暖橙灯笼＋深棕木质按摩店，叶植、白毛巾、琥珀精油瓶；角色正比偏可爱但不是统一 3 头身，**立绘约 4.5–6 头身（按参考图，假设）**，表情小窗可更 Q 版。木牌、牛皮纸、夹板、票据、红章构成 UI 语言。此前美术文档里的“约 3 头身”应以本次用户参考图为准修订。文字、数字和按钮状态必须在程序里排版，不能依赖生成图中的字样。

**色彩基准（假设，待原画取样定稿）**：暗木 `#39251F`、灯火 `#FFC15C`、旧纸 `#F2E4C7`、酒红 `#9E3039`、舒适绿 `#9BDF57`、耐心蓝 `#6FC4E9`、警示红 `#E8504F`、稀有金 `#F8CF67`。常态暖光，失败场景只在窗口／边缘叠红蓝冷光，保留人物原有肤色。

## 5. 最小程序接入包

将以下资源先做成真正可用的透明分层文件，才能把当前 `play.html` 的 Emoji／CSS 占位逐步换掉：

1. 阿烈与小曼：半身待机、左右手、6 表情、背部按压姿态，含 `hand_L_contact`／`hand_R_contact` 锚点。
2. 顾客吃货与轻柔控：趴卧身体、侧脸、6 表情、拒绝姿态；背部单独层。
3. S1 开背：`far/mid/bed/front` 分层与 4 张热区 mask；C02 可作重绘参考，不能直接截图抠层。
4. 道具：毛巾、精油、蛋糕三件透明图；四视图和接触点坐标。
5. UI：顾客档案纸板、左侧五状态条、底部道具卡、操作提示、胜败结算纸板；所有文字与数值在代码中排。
6. 特效：正确触点、滑动路径、舒适加分、失误／投诉预警四组透明素材。

**文件约定（假设）**：源文件 PSD／Krita／Figma；运行 WebP／PNG；UI 可拉伸面板九宫格；图集 ≤2048×2048，边缘 padding 4 px。角色、道具、场景与 UI 文件名使用稳定英文 ID，如 `scene_back_bed_front.webp`、`item_oil_held.webp`、`guest_foodie_face_relaxed.webp`。完整技术与验收规格见 [完整美术需求](../Massage_Mayhem_完整美术需求与验收_v1.md)。
