# 动画体验导演样机｜八名技师交互入口

入口：[index.html](index.html)。页面使用预生成的 `animation-bundle.js`，可在普通 Chrome 中直接双击本地文件打开，无需本地服务或额外浏览器开关。修改源文件后，在仓库根目录运行 `node build-standalone.cjs` 重新生成脚本。这是独立导演验证局，不写入正式游戏存档。

## 操作

1. 入场短步结束后，在虚线热区点击：准备 → 接触前 → 接触 → 顾客响应 → 收手，只结算一次。
2. 按住并在热区拖动：左右手 IK 跟随，躯干补位；顾客身体和脸在接触时响应。松开立即停止持续反馈，随后收手。
3. 选择道具：八名技师均有各自的试制道具箱；包师傅有前期美术清单的完整 19 件，另补用户压腿参考图中的按摩霜，共 20 件。点击不属于当前场景的道具会自动切到适用场景并拿取；动作进行中选择会排队。拿取后还需在虚线热区点击或拖动才能实际使用，最后道具归位。想提前放回可按“徒手”。食品的虚线热区会移动到顾客面前。库存或冷却造成的不可用状态会明确提示。
4. 点击“顾客突然乱动”或按 `G`：接触前取消结算，接触后撤手与顾客惊讶同步；拖出热区外围也会打断。
5. 专属技能：八名技师均可触发技能事件与规则结算；点击包师傅黄金右手会自动切至足疗。独立导演验证局会在重复预览时自动补满技能能量，动作进行中点击会排队；这不会改变正式游戏的能量规则或存档。芬姨递美食使用 `performService`，其他技师使用 `useSkill`。
6. 验证局达到胜利或失败终局后，再点击场景热区、道具或技能会自动开启下一次独立验证；右侧事件日志会重新开始。正式游戏仍按原规则结算。

## 架构与边界

- [item-catalog.js](../massage_mayhem_engine/item-catalog.js)：20 件道具的稳定 ID、角色库存、场景限制、护理/食品/整蛊规则映射与动作描述，由可玩关卡和动画样机共用。档案夹、投诉单、印章等 8 件文件道具仍属于 UI。
- [item-rules.js](../massage_mayhem_engine/item-rules.js)：逐件质量加成、使用次数、冷却、额外金币和舒适/好感/耐心/投诉修正；规则终局与原游戏保持同一优先级。
- [item-art.js](../massage_mayhem_engine/item-art.js)：20 件道具各自的 SVG 试制手持形状及接触特效，供开发者检查动作接口。正式美术仍需逐件补陈列图、按钮图、手持层和接触端图。
- [interaction.js](interaction.js)：与 DOM 无关的输入阶段、接触事务、中断、力度/路径质量。一个 interaction ID 最多一次规则结算。
- [visuals.js](visuals.js)：分层 SVG 试制角色（头、躯干、双臂、手、腿、道具）与独立顾客局部层；使用旧样机可复用的双骨 IK 求解器。三场景背景仍取原概念图。人物与顾客主体是程序绘制占位层，**并非正式原画分层资产**。
- [main.js](main.js)：浏览器输入映射、事件日志、既有规则引擎适配和 HUD。
- [interaction.test.mjs](interaction.test.mjs) 验证点击、长按拖动、入场、中断、道具与包师傅技能。`browser-smoke.cjs` 在 Chrome 测试实际页面、角色切换、热区边缘接触点、规则数值与手机宽度；运行需本机安装 Playwright，必要时通过 `CHROME_PATH` 指定 Chrome。

当前八人均可选择、按摩、拿道具、受打断及使用技能；每人有独立的试制体型、发型、衣装配色和道具库存。阿烈、芬姨和包师傅有第一批较完整的动作验证；其余五人的专属动作目前仍共用阶段节拍，只接入了角色参数和技能规则，**未完成各自的专属表演或正式美术**。20 件道具已逐件接入选择→拿取→接触→规则结算→归位链路，并在动画样机与原可玩关卡共用使用次数、冷却、花费和数值修正；基础偏好仍按 `gentle / strong / food / prank` 服务组判定。正式美术审批需要先完成 [素材生产与排期验收计划](../docs/animation/04_素材生产与排期验收.md) 所列三视图、遮挡补绘、表情组件、握持手形、逐姿势修形与绑定，再逐条审核走路脚滑、转身、工具端接触、顾客各场景坐卧姿势以及喜剧节奏。当前样机只证明交互事件因果与可替换分层接口，**不构成视觉与整体动画体验验收通过**。

整批 8 名技师、7 类顾客、3 场景的规划见 `docs/animation/`；其余 5 名技师的正式专属表演与 6 类顾客的正式资产仍等待第一批导演审批后制作。
