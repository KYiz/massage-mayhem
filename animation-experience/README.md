# 动画体验导演样机｜第一批

入口：[index.html](index.html)。建议从仓库根目录执行 `python -m http.server 8000`，打开 `http://localhost:8000/animation-experience/`；Chrome 直接打开本地文件也可运行（需允许本地 ES module 文件读取）。这是独立导演验证局，不写入正式游戏存档。

## 操作

1. 入场短步结束后，在虚线热区点击：准备 → 接触前 → 接触 → 顾客响应 → 收手，只结算一次。
2. 按住并在热区拖动：左右手 IK 跟随，躯干补位；顾客身体和脸在接触时响应。松开立即停止持续反馈，随后收手。
3. 选择毛巾或精油：先拿取、握持，再接触，最后放回；切换场景或技师会重置验证局。
4. 点击“顾客突然乱动”或按 `G`：接触前取消结算，接触后撤手与顾客惊讶同步；拖出热区外围也会打断。
5. 专属技能：阿烈飞吻、芬姨递食物、包师傅仅在足疗使用黄金右手。能量预设为 100 只为导演测试；命中时分别调用现有 `useSkill` 或 `performService`，右侧为真实规则返回值。

## 架构与边界

- [interaction.js](interaction.js)：与 DOM 无关的输入阶段、接触事务、中断、力度/路径质量。一个 interaction ID 最多一次规则结算。
- [visuals.js](visuals.js)：分层 SVG 试制角色（头、躯干、双臂、手、腿、道具）与独立顾客局部层；使用旧样机可复用的双骨 IK 求解器。三场景背景仍取原概念图。人物与顾客主体是程序绘制占位层，**并非正式原画分层资产**。
- [main.js](main.js)：浏览器输入映射、事件日志、既有规则引擎适配和 HUD。
- [interaction.test.mjs](interaction.test.mjs) 验证点击、长按拖动、入场、中断、道具与包师傅技能。`browser-smoke.cjs` 在 Chrome 测试实际页面、角色切换、热区边缘接触点、规则数值与手机宽度；运行需本机安装 Playwright，必要时通过 `CHROME_PATH` 指定 Chrome。

当前三人有不同体型、发型、服装、入场步频、双手长度和专属动作方向，但动画仍以程序姿势插值为主。正式美术审批需要先完成 [素材生产与排期验收计划](../docs/animation/04_素材生产与排期验收.md) 所列三视图、遮挡补绘、表情组件、握持手形、逐姿势修形与绑定，再逐条审核走路脚滑、转身、工具端接触、顾客各场景坐卧姿势以及喜剧节奏。当前样机只证明交互事件因果与可替换分层接口，**不构成视觉与整体动画体验验收通过**。

整批 8 名技师、7 类顾客、3 场景的规划见 `docs/animation/`；其余 5 名技师和 6 类顾客等待第一批导演审批后制作。
