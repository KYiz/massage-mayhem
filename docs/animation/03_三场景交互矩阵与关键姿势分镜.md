# 三场景互动动作矩阵与关键姿势分镜 v1｜视觉审批稿

本稿规定动作和双角色因果顺序。**静态分镜不是已经完成的动画**；图像板只供 Game Director 审造型与姿势。秒数、像素和阈值是 **假设**，浏览器样机手感验证后改。

## 1. 三场景交互矩阵

| 场景 | 顾客基础姿态与热区 | 点击（一次接触） | 长按（持续力度） | 拖动（跟随） | 工具演出 | 顾客乱动与恢复 |
|---|---|---|---|---|---|---|
| 开背 `back` | 趴卧；左/右肩、背中、腰背，顾客脸朝画面侧 | 技师先看背部，掌根下压 0.22 秒，床单与肩肉晚 2 帧反应 | 手掌保持贴合，肩和腰随压力往下 3–9 px；每 0.45 秒一个可读的呼吸/压力循环 | 手掌接指针目标，肘 IK 调整；移动超过单臂可及范围时脚步补位并转腰 | 毛巾：捏角→铺展→接触→收起；精油：拿瓶→倒滴→另一手抹开→归位 | 背部突然拱起，技师卸力收手；客脸立即变不适，手部归零后重新寻找肩/背热区 |
| 压腿 `legs` | 仰卧；左/右腿、膝周，腿托分层 | 技师托住腿部，下压/拉伸 0.3 秒；顾客膝先弯后伸 | 手掌保持支撑，腿角随力度缓慢改变，角度上限以顾客耐心反馈收窄 | 拖动方向映射腿部伸展向量，技师躯干随步幅移，禁止把整张顾客图平移 | 毛巾护膝、精油腿部抹开；握持点固定在工具/布角 | 顾客缩腿，双手先托住避免甩开，松压后退到安全角度，计一次中断 |
| 足疗 `feet` | 坐卧；左/右足底、足弓/脚跟；水面和盆沿遮挡 | 手指或掌根落在足底，脚趾/水波比手掌晚 2–4 帧 | 左手稳脚、右手持续按压；力度带动腕、肩与足部回弹；包师傅金光随真实接触保持 | 右手跟随足底目标，脚在水面上独立抬起；IK 超限时技师重站位 | 精油：左手拿瓶、右手抹油；毛巾：包脚擦干；包师傅先卸腕表再用右手 | 脚突然抽动，水花先起，技师立即放松抓握和金光，再观察顾客是否同意继续 |

每场景至少 4 个可读锚点：`guest_face`、`hotspot_center`、`hand_L_contact`、`hand_R_contact`；工具额外 `tool_grip` 与 `tool_tip`。热区基准 960×540 像素，运行时按 Canvas 到 CSS 像素换算。手掌锚点要在接触状态进入前距目标中心 **≤12 px（假设）**；否则不结算操作。

## 2. 六关键姿势通用分镜

| 镜号 | 时间（点击示例） | 技师：头/肩/腰/手/脚 | 顾客：表情/局部身体 | 事件和规则 |
|---|---:|---|---|---|
| P0 起始 | 0–0.10 s | 脚站稳、眼看顾客；肩放松、双手在身体前 | 中性，按场景躺卧 | 仅显示可操作热区，不计分 |
| P1 准备 | 0.10–0.24 s | 头先确认位置，躯干前移，手掌张开，脚底压住地面 | 眼神转向手，轻微预期 | 输入被锁定到本次 interaction ID |
| P2 接触前 | 0.24–0.38 s | 肘逐渐伸直，腰与肩补位，掌根距皮肤约 8–12 px | 皮肤/被单尚未形变 | 若顾客移位，撤手并取消本次计分 |
| P3 接触 | 0.38–0.46 s | 掌根最后 8–12 px 下压；脚和腰同帧稳住 | 肩/腿/足局部轻压，表情晚 2 帧变化 | `contactStart`，确认锚点和同意，接触 VFX 开始 |
| P4 顾客响应 | 0.46–0.64 s | 保持手部压力，不突然回收；头看顾客反馈 | 舒服则放松，不适则绷紧或缩回 | 本次 `performService`（或拒绝）在有效接触完成后结算；数值和表情同帧更新 |
| P5 结束/恢复 | 0.64–0.95 s | 手先减压后离开，肩回位、脚步归中，最后恢复表情 | 局部身体回弹，表情由峰值过渡到待机 | `contactEnd`，停止持续 VFX；可接下一次输入 |

长按把 P3–P4 延展为持续循环，**不是延长整张人物贴图**。拖动在 P3–P4 内持续更新 `hand_R_contact` 与 IK；若目标改变幅度大，脚步/腰部作为第二层补偿。松开必须从 P4 进入 P5，并在同一帧停止顾客持续反应。

## 3. 重要互动的镜头与节拍覆盖

### 3.1 点击/按压：阿烈开背轻柔

P0 侧身斜站、挑眉；P1 指腹悬在肩上方；P2 腕先翻、肘后伸；P3 双手一轻一重落在肩背；P4 顾客脸转向镜头眯眼、背部放松；P5 阿烈歪头笑，手掌离开后才整理袖口。总 0.95 秒，性格重点在“先炫技再稳稳接触”。

### 3.2 长按/拖动：芬姨足疗暖压

P0 先看顾客脚；P1 左手托足跟、右手掌根打开；P2 身体靠近而非手臂无限拉长；P3 右掌压足弓；P4 围裙轻摆、顾客脚趾和肩同时放松，力度过大时芬姨先察觉再收力；P5 两手松开，先把脚放稳才撤开。长按 0.4–2.5 秒可控，拖动时右掌跟随、左手托脚锚点不漂移。

### 3.3 工具：毛巾与精油

P0 工具在托盘；P1 技师手指找到 `tool_grip`；P2 工具随手转向目标（毛巾展开/瓶口朝下）；P3 `tool_tip` 与热区重合；P4 顾客局部反应与数值变化；P5 工具先离开皮肤，再回托盘。工具使用中途松开或顾客乱动必须取消持续效果，不能遗留油滴/毛巾贴图。

### 3.4 中断：顾客突然缩腿/抽脚

任意阶段出现乱动：**先停止压力与规则累积 → 技师手保持短暂跟随避免穿模 → 顾客局部后缩和脸部不适 → 技师撤手并做角色专属惊讶 → 重新观察锚点**。阿烈滑步侧让、芬姨先稳托盘、包师傅金光熄灭并收右手。中断时不得补发 `contactStart` 或结算。

### 3.5 包师傅黄金右手

P0 右手松放、左手托脚；P1 卸表/活动指节；P2 右肩与腰下沉，金光从手心开始；P3 右掌根压足弓、左手稳脚；P4 顾客脚趾/水波/脸/投诉条同帧响应；P5 收掌→金光消散→顾客表情回落。全长约 2.55 秒（假设）；中断时金光 0.12 秒内消退。

## 4. 输入、动画、规则的原子事务

每次交互使用递增 `interactionId`。输入事件为 `pointerDown`、`pointerMove`、`pointerUp`、`pointerCancel`；动画事件为 `contactStart`、`pressureChange`、`contactEnd`、`interrupted`、`recovered`；规则事件为 `serviceCommitted`、`refused`、`complaintFailed`。一次交互最多结算一次，不允许在 `pointerMove` 每帧刷分。

质量评分草案（假设）：`quality = clamp(40×落点精度 + 25×路径跟随 + 20×力度稳定 + 15×完成度, 0, 100)`，各子项归一化到 0–1。点击时路径跟随按该服务的点击模板给基准值 0.65；拖动按有效目标轨迹计算。仅有效接触满 **0.12 秒**且玩家松开/动作自然结束后调用规则层 `performService`。顾客明确拒绝后立即退出，不继续加压。包师傅主动技能使用规则层 `useSkill`，不在动画层私自改数值。

可视调试 HUD 同时显示：阶段、interaction ID、指针点、左右手接触点、热区点、力度、顾客状态、规则数值、最近事件。玩家模式可隐藏调试 HUD，但不得隐藏风险/拒绝反馈。
