# 八名技师动作导演表 v1｜待 Game Director 审批

角色为成年人。表演基调：参考概念图的厚描边、暖肤色、黑/酒红与花围裙等辨识造型；动作夸张但重心、肩肘和手掌接触有物理依据。以下秒数均为 **假设**，第一批浏览器样机调校后锁定。通用接口统一为 `idle / walk / turn / observe / gentle / strong / toolTake / toolUse / toolReturn / happy / angry / shocked / fail / signature / interrupted`，每人用不同节拍和关键姿势覆盖，不共享一模一样的画面。

## 01 阿烈 `charming_m`｜轻佻、自信、带舞步

- **站立/重心**：重心落右腿，左脚向外 15°，右肩略低，左手插腰；眼神先扫顾客再看自己的手。待机 2.2 秒循环，发梢轻摆但胸口不夸张起伏。
- **行走/转身/到位**：两步半走近床边，每步约 0.38 秒，脚尖先着地；到位前半步转髋 25°、肩后跟，头最后回望。不能脚底滑行。
- **观察**：上身前倾 8°，挑一侧眉，停 0.18 秒确认热区；拒绝线索出现时收起笑容。
- **轻柔/大力**：轻柔是腕部画弧、指腹先接触，胸口保持松弛；大力先屈膝、骨盆降低约 8 px，再让肩压下去，手掌最后抵达。两种动作不可只改播放速度。
- **道具**：拿精油前用余光定位，手指包住瓶颈；涂抹时另一手托住瓶底，放回时把瓶底稳稳落到托盘。毛巾要有捏角、展开和收回。
- **情绪**：开心时歪头并甩袖；愤怒时笑容僵住、眉压低；震惊时后退半步、手停在空中；失败时整理衣领掩饰慌乱，2 帧后才垂肩。
- **专属** `flying_kiss`：0–0.25 秒指尖碰唇；0.25–0.52 秒转腕送出飞吻；0.52–0.8 秒扭腰接短舞步；特效心形与顾客反应只在事件帧出现，不替代手部接触动作。
- **被打断**：顾客突然移位，阿烈先定住手腕 0.08 秒、滑步侧让、再看顾客脸；若被拒绝，表情从自信转成短促的无辜。

## 02 小曼 `charming_f`｜优雅、轻柔、魅力

- **站立/重心**：重心平衡，脚尖微外开，双手轻搭腹前；高马尾有延迟摆动，不能与头同帧硬转。
- **行走/转身/到位**：小步靠近，每步 0.32 秒；先移脚、再转腰与肩，最后马尾回弹 0.15 秒。
- **观察**：俯身看顾客表情，眨眼后才判断强度，手掌停在距皮肤 18 px 的预备位。
- **轻柔/大力**：轻柔用掌根小幅连续压力，手指保持舒展；大力时明显增加肩和腰参与，但手仍保持稳定，不使用猛砸式动作。
- **道具**：双手稳稳托起毛巾，展开成弧；拿瓶时小指收拢，接触后擦拭并归位。
- **情绪**：开心是微笑和轻点头；愤怒是突然冷脸、双臂收紧；震惊是睁眼并后缩；失败先维持职业笑容再泄气。
- **专属** `heart_gesture`：手在胸前汇拢 0.35 秒形成爱心，轻推到顾客视线，心形特效滞后 0.08 秒；不能把爱心当成按摩触点。
- **被打断**：立即移手离开身体、抬眼询问，回位后重新观察；若顾客明确拒绝，停手并轻微后退。

## 03 老冯 `uncle`｜沉稳、有重量

- **站立/重心**：宽站距，骨盆低，毛巾压肩；大手掌自然垂放。待机仅有缓慢呼吸和毛巾松动。
- **行走/转身/到位**：脚跟先落地，每步 0.5 秒；转身先脚后髋，肩最后带动，停下时明显有重量沉降。
- **观察**：眯眼量手距，用拇指试探肌肉弹性，观察 0.28 秒才落掌。
- **轻柔/大力**：轻柔仍用全掌缓推，幅度短；大力屈膝蓄力 0.32 秒，力量经脚→髋→肩→掌传递，接触帧肩不能已经回弹。
- **道具**：热石用拇指与三指包握，拿取与归位都停半拍确认温度；毛巾可顺手甩上肩。
- **情绪**：开心是闭眼点头；愤怒是鼻翼绷紧、手握拳；震惊只后退半步但眉挑高；失败慢慢放下毛巾、叹气。
- **专属** `charged_press`：双脚扎稳→两掌对齐→深呼吸蓄力→一次低位重压，释放时肩和床单均有延迟回弹。
- **被打断**：力量先卸到脚，掌心离开热区再抬头；不可直接把整只胳膊弹开。

## 04 芬姨 `aunt`｜热情、圆润、爱唠嗑

- **站立/重心**：重心略前，圆润躯干轻摆，双手习惯性准备招呼客人；花围裙下摆独立回摆。
- **行走/转身/到位**：短而快的小步，每步 0.28 秒；转身先头与手招呼、身体和围裙延迟 0.12 秒跟上，停步时肚腹轻弹。
- **观察**：侧头贴近顾客脸，手先托住被角，口型像在问“舒服吗”；看到不适立即收话。
- **轻柔/大力**：轻柔用掌根暖压，双肘圆弧；大力先撸袖、肩与腰同步前探，接触后用身体小幅缓压，不能像老冯那样猛压。
- **道具**：托盘先由左手接住，右手递蛋糕/毛巾；使用油瓶时两手短暂换位；放回时托盘微倾再扶正。
- **情绪**：开心拍掌并露出大笑；愤怒双手叉腰；震惊手中托盘抖一下；失败先安慰顾客，再回头懊恼。
- **专属** `offer_food`：左手托盘进入→右手指向食物→身体前倾递到顾客视线→确认接受后松手；若拒绝，立刻撤回而非强塞。
- **被打断**：惊得差点撒掉食物，托盘先稳住、再撤另一只手，随后重新询问；第一批重点验收短臂与宽躯干的 IK。

## 05 岚姐 `gentle`｜克制、精准、干练

- **站立/重心**：躯干笔直，重心居中，双手靠近身体；眼镜和衣领是稳定轮廓。
- **行走/转身/到位**：两步直线抵达；转身时脚先定位、躯干整体转，停下无多余晃动。
- **观察**：推眼镜、快速扫部位图与顾客反应，短暂停 0.12 秒，用食指点出接触区。
- **轻柔/大力**：轻柔用指腹精准小范围压点；大力也不大摆臂，肩胛下压幅度更深、掌根保持垂直。
- **道具**：拿精油瓶时先校准标签/瓶口朝向；使用后擦净瓶口再放回原位。
- **情绪**：开心只微扬嘴角；愤怒眼神变冷；震惊是镜片反光与一瞬停顿；失败摘眼镜揉眉心。
- **专属** `glasses_precision`：推镜→锁定热点→两指精准接触→光点沿肌肉线短暂传播；特效须服从真实手指位置。
- **被打断**：立即收指并侧身避让，重新瞄准前不发接触事件。

## 06 阿虎 `power`｜幅度大、先蓄力后发力

- **站立/重心**：宽肩、护腕，双脚大站距；胸背展开，但肩不能僵硬耸起。
- **行走/转身/到位**：大步两拍接近，最后一步降重心；转身有明显肩部惯性与护腕尾部回摆。
- **观察**：抬脚托/腿托确认角度，握拳后再张掌，等待顾客可接受的力度提示。
- **轻柔/大力**：轻柔刻意放慢且拘谨，夸张地小心；大力用脚步发力，髋向前、肩随后，手掌最终贴合，恢复有强回弹。
- **道具**：热石/足盆以双手提拿，放下时有重量沉降；拖鞋捏后跟，不抓尖端。
- **情绪**：开心竖拇指；愤怒咬牙握拳；震惊大幅后仰；失败护腕松脱、慌忙扶正。
- **专属** `heavy_foot_press`：腕部绕圈→蹲身蓄力→足弓压下→脚趾弹跳与水波反应，风险预警同帧出现。
- **被打断**：先把力量收进腿部，再抬手；若继续惯性前冲，触发失误而非无害动画。

## 07 小周 `joker`｜笨拙、紧张、易手忙脚乱

- **站立/重心**：双脚并得太近，肩缩、工服袖口偏长，胸袋小抄显眼。
- **行走/转身/到位**：步子忽快忽慢，停步时多滑半步再找平衡；转身头先转但脚慢半拍。
- **观察**：偷看小抄→看顾客→又看小抄，眼神与手部动作错拍但最后确认目标。
- **轻柔/大力**：轻柔时手指悬停太久，落掌后才放松；大力用力过猛会打滑，需用恢复动作自嘲。
- **道具**：两手换握两次才拿稳瓶子；工具用后往错误托盘放，发现后急忙改正，真实接触状态不能因此失控。
- **情绪**：开心比耶；愤怒想发火又忍住；震惊全身石化 0.16 秒；失败僵住后碎步退场。
- **专属** `prank_freeze`：整蛊准备→鬼脸→顾客反应→本人比顾客先石化；喜剧时点靠先后错位。
- **被打断**：差点摔倒、双手乱挥，但最先从顾客身体撤离工具，随后重新找准锚点。

## 08 包师傅 `bao_master`｜江湖气、老练、黄金右手

- **站立/重心**：宽肩、松膝，腰间毛巾与手表形成识别点；右手比左手更醒目，不能仅靠金光表示能力。
- **行走/转身/到位**：脚跟重落、步幅短而稳；转身先回头瞥顾客，再转腰肩，右手最后露出。
- **观察**：眯眼判断足部承受力，先用左手试探触点，再活动右手指节；普通客被拒绝时不强按。
- **轻柔/大力**：轻柔为慢推脚掌，用左手稳脚；大力是两脚扎稳，肩下沉，右掌根定向压足弓，左手固定脚跟。
- **道具**：先把手表卸下放入托盘，擦毛巾并归位；足浴油瓶由左手拿，右手保持干净。
- **情绪**：开心露出得意笑；愤怒鼻翼收紧；震惊手指僵住、眉上扬；失败把毛巾重新搭肩，嘴硬后泄气。
- **专属** `golden_right_hand`：0–0.3 秒卸表；0.3–0.7 秒活动指节；0.7–1.25 秒右掌金光蓄力、左手稳脚；1.25–1.55 秒右掌贴足弓；1.55–2.15 秒顾客脚趾/水波和风险条同步反馈；2.15–2.55 秒收手、光消散。若投诉阈值触发，成功表情立即改为警觉。
- **被打断**：左手先松脚，右手卸力贴近自己身体，金光中断并逐帧消失；不能剩余发光而手已经离开。

## 共用与差异的制作边界

| 层 | 可以共用 | 每人必须定制 |
|---|---|---|
| 运行逻辑 | 接触事件、手部 IK、状态切换、规则适配接口 | 各动作节拍、接触半径、角色失误阈值、专属技能钩子 |
| 动作结构 | 准备→蓄力/移动→接触→反馈→恢复的时间轴模板 | 肩/腰/脚步关键帧、手形、头眼表情、服饰二级运动 |
| 美术 | 纸张 UI、场景远景、通用特效基底 | 三视图、骨骼件、发型、服饰、手掌形状、特效配色和专属道具 |

第一批只制作阿烈、芬姨、包师傅和一名顾客的可交互试制。其余 5 名技师、6 类顾客的动作导演要求在本表先锁定；**不以三人试制图简单换色复制到其他人**。
