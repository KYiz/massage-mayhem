# 动画架构技术样机

当前阶段：**通用架构＋阿烈/芬姨体型验证＋包师傅技能验证**。所有人物和场景以 Canvas 几何图形显示，不是正式美术交付。完整美术分层和复用要求见 [美术分层与动画复用矩阵](./美术分层与动画复用矩阵.md)。

## 运行

需要 Node.js 24+ 和现代浏览器。构建无需下载依赖：

```bash
cd animation-prototype
node build.mjs
node --test test/*.test.mjs
```

在仓库根目录启动本地 HTTP 服务（例如 `python -m http.server 8000`），打开 <http://localhost:8000/animation-prototype/>。浏览器不支持直接加载 TypeScript，页面运行 `dist` 内的生成 JavaScript。

## 验证步骤

1. 在开背场景依次选择阿烈、芬姨，点击“伸手”和“按摩”；比对手掌与热区的距离和不同身形的弯肘姿势。
2. 按摩未结束时点击“失败”或“拿道具”；事件日志应显示动作中断，且不补发未到时间的接触事件。
3. 切到足疗、选择包师傅，点击专属技能；可见卸表、右手蓄力、金光与接触帧。切回开背时该技能禁用。
4. 轮流切换 7 类顾客及三种场景姿态，用表情和共用动作按钮检查入场、舒服、疼痛、拒绝、投诉、离场。
5. 如有正式分层 PNG，可按 `src/data.ts` 指定路径放入 `assets/`，勾选“尝试加载分层 PNG”检查替换。缺失素材仍显示技术图形。

TypeScript 当前通过 Node 24 自带的类型剥离生成 JS，这一步不做静态类型检查；接入正式 Phaser 工程时须用标准 TypeScript 编译器做严格类型检查。
