# Massage Mayhem — 可玩规则框架

## 运行

需要 Python 3 和现代浏览器：

```bash
cd massage_mayhem_engine
python -m http.server 8000
```

打开 **http://localhost:8000/play.html**。不能直接双击 HTML，因为浏览器会限制本地 ES Modules。`index.html` 和 `campaign.html` 保留为旧版独立调试原型。

## 自动检查

需要 Node.js 20+，在本目录运行：

```bash
node --test
```

## 新版架构

- `game-rules.js`：纯规则函数。负责种子随机生成顾客和场景、稀有客邀请、手势评分、服务结果、技能、申诉、终局优先级、金币结算、解锁与冷却。
- `campaign.js`：浏览器界面控制与 `localStorage` 存档；将指针滑动的落点、距离、时间换算为 0–100 操作质量后调用规则层。
- `play.html`：可玩的关卡入口，包含技师轮盘、接单、滑动操作、战报与结算。
- `levels.json`：30 关数据源，`comfortGoal`、`patience`、`maxActions`、`servicePool` 与奖励均参与真实判定。
- `game-rules.test.js`：规则测试；覆盖关卡目标、种子重现、操作限制、终局优先级、拒绝、稀有客、重复领奖、技能和申诉。
- 隐藏技师“包师傅”：第 30 关通关后在轮盘出现，花 12,800 金币解锁；足疗重按与“黄金右手”已接入规则，完整数值见 `../art/包师傅_隐藏技师策划与美术卡.md`。
- `item-catalog.js`、`item-rules.js`、`item-art.js`：包师傅解锁后拥有 20 件可操作道具（前期清单 19 件＋按摩霜）。`play.html` 中的道具箱显示适用场景、本局剩余次数与冷却；使用走独立数值和金币修正，状态写入现有本地存档。其它技师保留各自较小的道具箱。道具 SVG 是开发试制件，正式透明分层美术仍待制作。

规则函数不读 DOM、时钟或本地存储。UI 与规则通过普通对象传递状态，后续可替换为 Phaser 表现层。存档格式版本为 2；旧版 `campaign.html` 的页面内进度不会自动迁移。

## 文件
- `engine.js`: 独立于界面的数据配置、状态、规则与事件函数。
- `index.html`: 最简互动场景、角色状态 UI 和按钮操作。

## 扩展建议
正式项目使用 Phaser 3 + TypeScript + Vite；将 `engine.js` 拆为数据配置、纯函数状态更新、事件系统、表现系统；用 seed PRNG 重放对局；将广告回调作为可替换 Adapter，并仅在确认奖励完成时解锁。不得把剧情说明误认作已经实现的功能。

## v1.3 关卡原型
- 新入口 `campaign.html`：30关进程、循环技师轮盘、🔒灰显与解锁、按关卡生成顾客、稀有客的接受/拒绝、模拟结算。
- `levels.json`：每关服务/场景/顾客池/难度/奖励/事件解锁参数。
- `rare_customer.json`：神秘客阈值、冷却与奖励定义。
- `progression.js`：可种子化概率、解锁、生成、结算的规则示例（依赖支持 JSON module import assertions 的环境）。
- 注意：campaign.html 使用独立的 UI 进程模拟，尚未将实际按摩战斗与进程持久化接通；刷新后重置；不代表完整游戏。
